# BUG 风险评估工具

单文件、纯前端（浏览器内计算）的 BUG 风险评估工具：拖入 Excel BUG 清单，自动对每条 BUG 做 10 维打分，输出风险分 / 等级 / 结构化风险描述，并可回写 Excel 与导出 Markdown 报告。

## 使用

1. 用浏览器打开 `BUG风险评估工具.html`（首次加载需联网获取 Chart.js / SheetJS CDN）。
2. 拖入或选择 BUG 清单（`.xlsx` / `.xls` / `.csv`），可直接用 `示例BUG清单.xlsx` 体验。
3. 五个页签：
   - **总览**：汇总卡片、等级分布、TOP15 排行、权重配置。
   - **风险清单**：按风险分降序，可按等级筛选，点击行进入详情。
   - **单条详情**：查看/拖动滑条修正 10 维打分，实时重算风险分、等级与风险描述。
   - **风险矩阵**：影响范围 × 发生概率 热力图。
   - **报告**：Top 高风险清单与汇总。
4. 导出：
   - **导出结果 Excel（回写）**：原始列 + 风险总分/等级/风险陈述/Top维度/缓解措施/一句话结论/建议优先级，含「风险等级分布」「风险矩阵」两个附加 Sheet。
   - **导出评估报告(.md)**：Markdown 周报。

## 打分模型

- 10 个维度（默认权重，可在总览页调整）：严重程度 20%、影响范围 12%、发生概率 12%、业务影响 10%、数据与安全 15%、修复成本 8%、紧急程度 10%、依赖与连带 8%、检测与恢复 3%、根因与技术债 2%。
- 风险分 = Σ(维度分 × 权重) / Σ权重，映射到 0–100。
- 等级：P0 紧急(≥80)、P1 高(≥60)、P2 中(≥40)、P3 低(≥20)、P4 可忽略(<20)。
- 一票升级规则：数据与安全 ≥4 分自动升 P0；优先级=紧急 直接判 P0。
- 自动推断依据：优先级/严重程度、状态（Reopen/More Info）、概要/描述关键词（必现/偶现/崩溃/越权/双端/跨机型等）、机型字段；缺失维度可在「单条详情」手动修正。

## 输入列自动识别

关键字、概要/标题/问题描述、优先级、严重程度、状态、组件/模块、经办人/负责人、报告人、MODEL/机型、日期、复现概率、影响范围、复现步骤/详细描述。表头行上方允许存在标题行（自动跳过）。

## 说明

- 所有数据在浏览器本地处理，不会上传。
- 打分引擎为纯函数，位于 `BUG风险评估工具.html` 内 `/*__ENGINE_BEGIN__*/` 与 `/*__ENGINE_END__*/` 之间，可独立于 UI 进行测试。
